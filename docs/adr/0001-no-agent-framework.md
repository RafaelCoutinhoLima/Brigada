# 0001. Construir o runtime de agentes sem framework

- Status: proposta
- Data: 2026-10-28

## Contexto

Frameworks de agentes aceleram protótipos, mas escondem o loop de tool use, a política de retry, o estado da execução e o controle de custo. Este projeto existe para dominar essas peças.

## Opções consideradas

1. LangChain / LangGraph: rápido de começar, abstrações pesadas, difícil de depurar.
2. SDK oficial da Anthropic + código próprio: mais trabalho, controle total e cada decisão explícita.
